Eerie Woods

Eerie Woods is a fictional horror survival game concept where players must escape a haunted forest filled with mysterious entities and unknown creatures hunting them down. As players explore deeper into the woods, they must survive dangerous encounters and navigate the unknown while searching for a way out.

Project Details:

• Solo Project
• Role: Game UI Designer
• Built in Figma
• 3 Week Development

Responsibilities

  • Designed and created six interface screens including the main menu, gameplay screen, pause menu, inventory screen, and settings menu.
  • Created an interactive prototype in Figma by connecting screens through navigation flows, allowing users to click through scenes and simulate the overall user experience in the game.
  • Developed a consistent visual style across all screens to match the horror atmosphere and overall game theme.
  • Designed UI layouts with minimal elements to improve clarity, readability, and user experience.
  • Focused on balancing visual presentation with functionality to support navigation and gameplay interactions.

The Design Process

Pre-Production

During the pre-production stage, I brainstormed how the interface screens could be designed effectively while maintaining consistency, clarity, and a strong focus on user experience. Early planning focused on organizing screen layouts, navigation flow, and visual structure to ensure each interface felt connected while supporting usability across the overall game experience.

From there, I created rough sketches and layout concepts to organize ideas and visualize the overall interface structure. These early concepts helped establish the placement of UI elements, screen flow, and visual direction before moving into the digital design process.

Design & Execution

Game Interface Design

The interface screens were designed with a focus on consistency, clarity, and user experience. Each screen maintained a connected visual style while using minimal elements to avoid clutter and make navigation easier for players. It also demonstrates a consistent theme across all of the interface elements.

Horror Visual Style

The visual style was designed to support the horror survival theme through dark environments, simple layouts, and atmospheric elements. Dark colors and visual effects were used to create a feeling of mystery and tension while exploring the haunted forest. At the same time, the interface was kept simple so important information could remain clear and easy to understand.

Iteration & Final Delivery

Interactable Prototype Design

An interactive prototype was created in Figma to simulate the full user experience by connecting screens together through navigable flows. This allowed users to move between scenes and experience how the interface would function within the game environment. The prototype helped visualize screen transitions and gave users a better understanding of the overall gameplay flow and interface design.

Final Interface Implementation

The final version of Eerie Woods was completed with a total of six interface screens, including the main menu, gameplay screen, pause menu, inventory screen, and settings menus. Each screen was designed to remain visually connected and fit the overall horror theme of the game. The design is also very simple, with minimal elements as possible for clarity.
